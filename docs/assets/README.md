# Wearly — assets

This folder holds README hero imagery once captured.

To complete the README hero block:

1. Deploy this repo to Streamlit Community Cloud (one-time, ~5 min).
2. Replace the "coming soon · deploy this repo..." line in the root
   `README.md` with the actual Streamlit Cloud URL.
3. Either take a desktop screenshot at the centered 720px canvas width
   or record a 60–90 second GIF of the full flow:
     - land on the home,
     - tap "Plan today's outfit →",
     - watch the outfit + reasoning render,
     - open the "Not quite right?" block,
     - reject an item, regenerate, see the "What changed" banner.
4. Save the file as `docs/assets/hero.png` (or `hero.gif`) and update
   the README image reference accordingly.

The placeholder image path in README.md is `hero-placeholder.png` so
the markdown remains valid even before the real asset is produced —
GitHub will simply show a "missing image" icon until the file exists.
